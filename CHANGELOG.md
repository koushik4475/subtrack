# Changelog

## 0.1.0 — Initial release

- Offline-first subscription and recurring-payment dashboard.
- Subscription CRUD, lifecycle status changes, and paid-renewal events.
- Weekly, monthly, quarterly, half-yearly, yearly and custom day-interval billing.
- Renewal timeline, trial conversion warnings, filters and search.
- Currency-grouped monthly/yearly estimates and payment history trend.
- Price history, validated JSON backup/restore and local-only IndexedDB storage.
- PWA shell, GitHub Actions CI and Cloudflare Pages integration.
